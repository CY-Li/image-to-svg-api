使用說明

  1. 首先需要取得 Google Gemini API Key（免費申請）
  2. 輸入您的品牌或公司名稱
  3. 描述您想要的 Logo 風格和特色
  4. 選擇主要色調（建議使用深色系）
  5. 點擊「開始產生 Logo」按鈕
  6. 等待 AI 生成完成後下載您的 Logo

常見問題

如何取得 Google Gemini API Key？

前往 Google AI Studio 免費申請 API Key。

Logo 生成需要多長時間？

通常需要 10-30 秒，具體時間取決於 AI 處理複雜度。

支援哪些輸出格式？

支援 SVG 向量格式和 PNG 圖片格式，SVG 格式可無限縮放不失真。
